# X-Banner Smart Flower Irrigation

Sistem Monitoring Lingkungan dan Irigasi Otomatis pada Budidaya Tanaman Bunga berbasis IoT (ESP32).
Teknik Elektro, Universitas Jember.

- `index.html` : X-Banner interaktif (satu file, tanpa dependensi, logo sudah tertanam)
- `XBanner_60x160cm.png` : gambar resolusi tinggi untuk dicetak (60 x 160 cm)

## Cara upload ke GitHub Pages
1. Buat repository baru di GitHub (mis. `xbanner-irigasi`), pilih Public.
2. Klik **Add file > Upload files**, seret semua isi folder ini (termasuk `.nojekyll`), lalu **Commit changes**.
3. Buka **Settings > Pages**, pada *Build and deployment* pilih **Deploy from a branch**, branch `main`, folder `/ (root)`, lalu **Save**.
4. Tunggu 1-2 menit. Alamatnya: `https://USERNAME.github.io/xbanner-irigasi/`

Untuk QR Code: buat QR dari alamat di atas, lalu pasang di kotak QR (ketuk kotaknya di halaman).
